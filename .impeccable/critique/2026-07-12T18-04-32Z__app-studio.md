## Priority Issues
- [P1] Autosave reports success on a failed write (storage.ts catch{} + unconditional setSaving(false)). Fix: return boolean, add a "not saved" indicator state.
- [P1] Inspector (inset-inline-end-4 = physical left in RTL) collides with zoom controls (left-4) in the bottom-left corner. Fix: opposite edges.
- [P2] Four near-identical small-button treatments (IconButton/Stepper/ViewBtn/ToolBtn) + hand-rolled smart-apply button. Fix: consolidate into IconButton/Button.
- [P2] No Esc to deselect/dismiss inspector (keydown handler covers undo/redo/delete only).
- [P2] Core placement workflow is pointer-only; keyboard users locked out. Utilization bar lacks role=progressbar.
